Getting Started

Launch the Application

On Linux or macOS, open a terminal in the project folder and run the launcher for your system:

  • Linux: ./Linux_Oscilloscope_Studio.sh
  • macOS: ./Mac_Oscilloscope_Studio.command

On Windows, double-click Windows_Oscilloscope_Studio.bat.

The first run downloads a project-local Python runtime and the required packages. Internet access is required for this initial setup and for application updates.

Keyboard Shortcuts

  • Ctrl+R or Command+R: restart the application.
  • Ctrl+Q or Command+Q: quit the application.
